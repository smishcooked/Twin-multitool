How to Run on Windows

WARNING: Security software may flag certain components as suspicious. Do not disable your antivirus or run unknown token-logging code. Review the source code before running anything.

Open the Twintool V2 directory.
Locate SETUP.bat. Do not run START.bat first, or it may not work.
Run SETUP.bat.
Once setup is complete, run START.bat.
Enjoy!
Error or Bug Fixing

If you encounter an error, check the relevant error message and follow the appropriate troubleshooting steps.

If you get the following error:

Python was not found; run without arguments to install from the Microsoft Store, or disable this shortcut from Settings > Manage App Execution Aliases.

Install a compatible version of Python (3.8–3.10) from the official Python website or another trusted source, then run SETUP.bat again.

How to Run on macOS or Linux
Install Python 3.8–3.10 from python.org.
Install pip if it isn't already available.
Rename SETUP.bat to setup.txt so you can inspect its contents.
Open the file and review the package installation commands.
Install the required dependencies using the appropriate commands for your operating system.
Open the individual tools, not menu.py.
Run compatible tools manually from your terminal.
Enjoy!
